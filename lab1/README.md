# Лабораторная работа №1: Введение в машинное обучение и подготовка данных

## 1. Описание проекта

Применение базовых инструментов Data Science (Python, Pandas, Scikit-learn) для проведения полного цикла аналитики и построения модели классификации на основе реальных экономических данных Kaggle

## 2. Структура

**Структура репозитория:**

1. `README.md` — краткое описание проекта, выбранного датасета и итоговых аналитических выводов.
2. `bank.csv` — датасет маркетинговой кампании банка (https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset)
3. `SkripkoDanil_4231133_lab1.ipynb` — Jupyter Notebook с полностью исполненным кодом, построенными графиками и текстовыми Markdown-пояснениями к каждому этапу.
4. `requirements.txt` — зафиксированные зависимости виртуального окружения.

## 3. Выбор датасета

Был выбран Bank Marketing Dataset — https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset

## 4. Вывод

Удалены столбцы poutcome (у большинства нет значений) и contact. На ящике с усами типичный возраст клиентов с депозитом и без него почти одинаковый. Одного возраста для прогноза недостаточно. Модель угадывает открытие депозита с accuracy 83.61%. Банк может сначала звонить клиентам, которых модель отметила как вероятных, тогда лишних звонков станет меньше, а согласий больше.
