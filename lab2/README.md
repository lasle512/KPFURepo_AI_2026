# Лабораторная работа №2: Метод k-ближайших соседей и непараметрические методы регрессии

## 1. Описание проекта

Применение непараметрических алгоритмов машинного обучения (kNN и Ядерная регрессия Надарая-Ватсона)
и изучение влияения метрик расстояния и гиперпараметров на качество прогнозирования реальных экономических показателей.

## 2. Структура

**Структура репозитория:**

1. `README.md` — краткое описание проекта, выбранного датасета и итоговых аналитических выводов.
2. `used_car_price_dataset_extended.csv` - датасет цен на поддержанные автомобили (https://www.kaggle.com/datasets/therohithanand/used-car-price-prediction)
3. `SkripkoDanil_4231133_lab2.ipynb` — Jupyter Notebook с полностью исполненным кодом, построенными графиками и текстовыми Markdown-пояснениями к каждому этапу.
4. `requirements.txt` — зафиксированные зависимости виртуального окружения.

## 3. Выбор датасета

Был выбран датасет цен на поддержаные автомобили - https://www.kaggle.com/datasets/therohithanand/used-car-price-prediction

## 4. Вывод

Модель вернее определяет ценовую категорию для поддержаных автомобилей среднего ценового сегмента, что поможет для их более быстрой продажи. Для дорогих/дешёвых проверку лучше делать вручную.
