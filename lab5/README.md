# Лабораторная работа №3: Метрики качества, кросс-валидация и пайплайны

## 1. Описание проекта

Изучил разрушительное влияние на наименьшие квадраты из-за проблемы мультиколлинеарности. Освоил применение L1 и L2.

## 2. Структура

**Структура репозитория:**

1. `README.md` — краткое описание проекта, выбранного датасета и итоговых аналитических выводов.
2. `used_car_price_dataset_extended.csv` - датасет о предсказании цен на поддержаные автомобили (https://www.kaggle.com/datasets/therohithanand/used-car-price-prediction?resource=download)
3. `SkripkoDanil_4231133_lab5.ipynb` — Jupyter Notebook с полностью исполненным кодом, построенными графиками и текстовыми Markdown-пояснениями к каждому этапу.
4. `requirements.txt` — зафиксированные зависимости виртуального окружения.

## 3. Выбор датасета

Был выбран датасет цен на предсказание цен поддержаных автомобилей - https://www.kaggle.com/datasets/therohithanand/used-car-price-prediction?resource=download

## 4. Вывод

Модель объясняет 88% разброса цен на автомобили, что позволяет использовать ее для быстрой автоматической оценки. Наиболее влияющие признаки: engine_cc, make_year, fuel_type_Electric и mileage_kmpl, увеличивающие стоимость, а также owner_count, её уменьшающее. Остальные параметры практически не учитываются при прогнозировании цены, для редких/спорных случаев нужна ручная проверка.
