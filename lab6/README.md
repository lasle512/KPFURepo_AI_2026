Освоил математическую и геометрическую интуицию, метод опорных векторов. Изучил влияние гиперпараметра $C$ и ядерного трюка

## 3. Выбор датасета

Был выбран датасет цен на выявление мошенничества с кредитными картами - https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## 4. Вывод

Модель предсказывает обычную операцию с точность 99.8%, такая точность возможна из-за недостатка данных по мошенникам (492 строки из 284807). Линейный SVM строит простую границу отсекая практически все мошеннические операции, но пропуская сложные случаи. RBF SVM имеет более гибкую границу, изолируя скопления.
Чтобы данную модель можно было использовать в банковской системе, надо добавить больше мошеннических операций в обучающую выборку.
Измененние $C$ не даёт иного результата
